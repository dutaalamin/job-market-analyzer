Which skills are the job market actually asking for?

An end-to-end data platform that collects job postings, models them in a dbt-managed warehouse, and answers that question with SQL.

Pipeline and orchestration

collect.py → transform.py → load.py → dbt → analyze.py

Scheduled daily by an Apache Airflow DAG. The dbt layer models the warehouse and enforces 27 data-quality tests, all passing.

Engineering note

The first version of this pipeline matched skills against a lowercased string. That made the English word “next” hit the Next.js pattern — and Next.js appeared as the single most in-demand skill with 501 postings, when only 16 postings actually mention it. One line, found by reading the output instead of trusting it.

# before — every “next week” became a skill - haystack = " ".join(texts).lower() - ("Next.js", r"\bnext(?:\.js|js)?\b") # after — ambiguous names keep their case, and need the “js” + haystack = " ".join(text for text in texts if text) + ("Next.js", r"\bnext\.?\s?js\b")

Covered by 21 regression tests, including every disambiguation that shipped wrong. The dashboard reports how much of the corpus yields a skill at all — a skill count is a count of postings that mention it, not a share of the market.
